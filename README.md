# DateTime

A live date and time app with an interactive calendar and dual-language support.

## Features

- Displays the current date and time.
- Browse dates with an interactive calendar.
- Dual-language support.

## Latest release

**Version:** [v0.0.1](https://github.com/MdKhalidHassan/date-time-calender-app/releases/tag/v0.0.1)

Download the Android APK: [DateTime.apk](https://github.com/MdKhalidHassan/date-time-calender-app/releases/download/v0.0.1/DateTime.apk)

To install, download the APK to your Android device and open it. Your device may ask you to allow installation from that source.

## Requirements

- Android 7.0 (API 24) or later.

## Build from source

1. Clone this repository:

   ```bash
   git clone https://github.com/MdKhalidHassan/date-time-calender-app.git
   ```
2. Open the project in Android Studio and allow Gradle to sync.
3. Run the `app` configuration on an emulator or connected Android device.

## Tech stack

- Kotlin
- Jetpack Compose
- Gradle
